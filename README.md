# Equipe Bruna

Equipe de 12 agentes de IA no Claude (app desktop, aba **Code**) para as três frentes da Bruna
Sardinha: **Cardume**, **UNDIME** e **SCP**. Montada pela NodeCompany.

**Para começar, abra o `COMECE AQUI.pdf`.**

## O que tem aqui
| Pasta | O que é |
|---|---|
| `CLAUDE.md` | Instruções gerais da equipe (lidas automaticamente pelo Claude) |
| `.claude/agents/` | Os 12 agentes |
| `.claude/skills/` | Habilidades: `configurar`, `ajuda`, `criativo-higgsfield`, `publicar-instagram` + skills de marketing |
| `.claude/hooks/` | Lembrete automático do Modo Configuração |
| `Empresas/<Empresa>/_base/` | O que a equipe sabe sobre cada empresa (fonte única de verdade) |
| `Empresas/<Empresa>/identidade/` | Logos, fotos e manual de marca |
| `Equipe/_base/regras.md` | Regras que valem para todos |
| `Configuracao/progresso.md` | Checklist do Modo Configuração |
| `Entregas/<Empresa>/` | Tudo que a equipe produz (fica só no computador da Bruna) |

## Escopo por empresa
- **Cardume** e **UNDIME**: equipe completa.
- **SCP**: só conteúdo (social media, legenda, criativo, vídeo), com as regras de publicidade médica
  do CFM.

## Atualizações (para o Junio)
Entrega por ZIP. Ao mandar uma versão nova, a Bruna **não** deve substituir a pasta inteira: as
pastas `Empresas/*/_base/`, `Empresas/*/identidade/`, `Configuracao/` e `Entregas/` têm o que ela
preencheu. Troque só `CLAUDE.md`, `.claude/` e `Equipe/`.

## Créditos
As skills de marketing em `.claude/skills/` são de terceiros (pacotes da comunidade Claude) e estão
como no original, com o arquivo de licença quando a pasta traz um. Repositório **privado**, para uso
da cliente: não publicar. As skills `configurar`, `ajuda`, `criativo-higgsfield` e
`publicar-instagram` são da NodeCompany.
