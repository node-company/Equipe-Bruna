## Problemas comuns (responda só o que ela perguntou)
- **"Apareceu um pedido de Permitir"**: é o Claude pedindo licença para agir. Pode aceitar se tiver a
  ver com o que você pediu.
- **"O Higgsfield/Google não funciona"**: confira em Configurações → Conectores se está conectado;
  abra uma conversa nova. Sem Higgsfield, a equipe entrega o prompt para colar no site.
- **"Postei no perfil errado"**: apague o post no app do Instagram (⋯ → Excluir) e reagende no
  certo.
- **"Quero mudar uma informação da empresa"** (preço, @, regra): diga "atualiza na base da <empresa>:
  …". A equipe inteira passa a usar.
- **"Travei numa tela"**: Windows + Shift + S, selecione, e cole aqui com Ctrl + V.
